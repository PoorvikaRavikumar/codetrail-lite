
# CodeTrail Lite

A web-based dashboard for tracking and viewing coding practice progress in one place.

**Live Website:** https://codetrail-lite.onrender.com/

## About the Project

CodeTrail Lite is a coding progress dashboard designed to help learners monitor their problem-solving journey. It displays solved problem statistics, difficulty-wise distribution, and recent coding activity through a simple and user-friendly interface.

## Features

- Welcome dashboard
- LeetCode profile display
- Total problems solved
- Easy, Medium, and Hard problem statistics
- Difficulty distribution chart
- Recent activity chart
- Analytics section
- Activity section
- Recommendations section
- My Profile section
